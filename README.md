# 🎬 CineBook – Movie Ticket Booking & Management System

## 📌 Project Overview
CineBook is a MySQL-based database management project designed to manage movie ticket booking operations. It maintains movie details, show schedules, customer information, bookings, and ticket records.

## 🛠️ Technologies Used
- MySQL
- SQL
- MySQL Workbench

## 📂 Database Tables
1. **Movies** – Stores movie titles, genres, languages, and durations.
2. **Shows** – Manages movie showtimes, screen numbers, and ticket prices.
3. **Customers** – Stores customer details and contact information.
4. **Bookings** – Maintains customer booking records and booking status.
5. **Tickets** – Stores seat numbers and ticket payment details.

## 🚀 Key Features
- Database and table creation.
- Primary Key and Foreign Key constraints.
- Unique and CHECK constraints.
- INSERT, UPDATE, and DELETE operations.
- ALTER, DROP, and TRUNCATE commands.
- JOIN operations.
- GROUP BY and ORDER BY clauses.
- Aggregate functions (COUNT, SUM).
- Transaction management using COMMIT and ROLLBACK.
- Ticket revenue analysis.
- Data validation and integrity checks.

## 📊 SQL Analysis
- Total customers, bookings, tickets, and shows.
- Booking status analysis.
- Confirmed ticket revenue calculation.
- Movie genre analysis.
- Hindi movie filtering.
- Top 5 longest movies.
- Invalid ticket reference checking.
